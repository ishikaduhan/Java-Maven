
# Calculator Maven JUnit Application

A simple Java calculator application developed using Maven and JUnit 5.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero exception handling

## Technologies
- Java 21
- Apache Maven
- JUnit 5
- Git
- GitHub

## Run Tests
mvn clean test

## Build Project
mvn clean package

## Run Application
java -cp target/classes com.example.Calculator
